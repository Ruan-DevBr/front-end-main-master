## 📚 Sobre o repositório

Este repositório tem como objetivo armazenar e organizar as atividades práticas desenvolvidas durante as aulas de Desenvolvimento Front-End.

Os exercícios apresentam conceitos fundamentais da construção de páginas web, permitindo colocar em prática os conhecimentos de estruturação, estilização e desenvolvimento de interfaces.

## ▶️ Como executar os projetos

1. Clone este repositório:
   ```bash
   git clone https://github.com/Ruan-DevBr/front-end-main-master.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.

3. Entre na pasta da aula desejada.

4. Localize o arquivo `index.html`.

5. Abra o arquivo diretamente em um navegador ou utilize a extensão Live Server no Visual Studio Code, caso disponível.

## 🎯 Objetivo de aprendizagem

Desenvolver conhecimentos e habilidades na criação de páginas web, compreendendo a estruturação de conteúdo com HTML5 e a estilização de interfaces com CSS3, além de aprimorar a organização e a construção de projetos para a Web.
